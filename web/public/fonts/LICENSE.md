# Fonts shipped with BLURT

Both faces are licensed under the **SIL Open Font License 1.1**, which permits
bundling and redistribution with an application. They are vendored here as latin-subset
`woff2` files and served from this origin — BLURT never calls a font CDN at runtime.

| File | Family | Designer / Foundry | Licence |
|---|---|---|---|
| `fredoka-500-600.woff2` | Fredoka (variable, wght 500–600) | Milena Brandão, Hafontia | SIL OFL 1.1 |
| `inter-400-700.woff2` | Inter (variable, wght 400–700) | Rasmus Andersson | SIL OFL 1.1 |

Full licence text: <https://openfontlicense.org/open-font-license-official-text/>

Both are used unmodified apart from subsetting to the `latin` unicode range, which the
OFL explicitly allows. Neither family name is used to describe a modified version.
